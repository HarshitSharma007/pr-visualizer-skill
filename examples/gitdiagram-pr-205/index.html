PR 205 / 01 of 03

main-card.tsx

src/components/main-card.tsx

CORE — read closelymodified+32 −30

What this file does: it renders the main repo card — the diagram area, the Regenerate and Export buttons, and the Enable Zoom switch a visitor uses on a repo page.

1. Card layout

Why this file changes

Why here?

On mobile the actions stacked one under another at uneven widths, and the zoom label and switch sat on separate rows — the card grew to 376px tall and was hard to scan. The fix has to live here, because this file owns the action row.

Input

A tall, uneven stack

Regenerate, Export and the zoom control pile up vertically on a phone. Each takes its own row, its own width, and its own large padding.

→
This file

Rebuild the action row

The row becomes a 2-column grid (grid-cols-2) on mobile: both buttons go full-width in their column at min-h-11, labels shorten to “Regenerate” / “Export”, and zoom moves into one full-width row (col-span-2) with a top divider. At sm: the old flex row and full labels return.

→
Result

A shorter, even card

Closed card drops from 376px to 278px tall at 390px wide, both buttons are comfortable 44px tap targets, and the layout still fits at 320px with no overflow.

Keep this distinction

No button changes what it does

Regenerate, Export and the zoom switch call the exact same handlers as before — only their size, position and mobile label text change. Shorter labels are a mobile-only space trade, not a rename: desktop keeps “Regenerate Diagram” and “Export Diagram”.

→
Result

2. Export tools

Why this file changes

Why here?

When the panel opens on a phone it added a lot of height — loose spacing, a roomy button and full-size notes made the expanded card the tallest state of all, 516px. Tightening this panel is what brings that state down to 416px.

Input

An airy panel on mobile

space-y-4 gaps, a gap-3 button row with desktop padding, and text-sm notes — comfortable on desktop, wasteful on a 390px screen.

→
This file

Tighten, don't remove

Mobile spacing drops to space-y-3 and gap-2.5; Download PNG gets the same h-11 w-full treatment as the Copy button; both notes shrink to text-xs on mobile. Every value steps back up at sm:.

→
Result

Same panel, 100px shorter

Expanded card: 516px → 416px at 390px wide. Every control and both notes are still there — just closer together and right-sized on small screens.

Keep this distinction

Nothing is hidden

Nothing is hidden on mobile to save space. Download PNG, “Last generated” and “Actual cost” all still render — they are smaller and tighter, not removed — and desktop spacing is completely unchanged.
