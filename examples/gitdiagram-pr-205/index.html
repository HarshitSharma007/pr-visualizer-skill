PR 205 / 01 of 03

main-card.tsx

src/components/main-card.tsx

CORE — read closely modified +32 −30

What this file does: it renders the main repo card — the diagram area, the Regenerate and Export buttons, and the Enable Zoom switch a visitor uses on a repo page.

1Card layout

Why this file changes

On mobile the actions stacked one under another at uneven widths, and the zoom label and switch sat on separate rows — the card grew to 376px tall and was hard to scan. The fix has to live here, because this file owns the action row.

Input

A tall, uneven stack

Regenerate, Export and the zoom control pile up vertically on a phone. Each takes its own row, its own width, and its own large padding.

This file

Rebuild the action row

The row becomes a 2-column grid (grid-cols-2) on mobile: both buttons go full-width in their column at min-h-11, labels shorten to “Regenerate” / “Export”, and zoom moves into one full-width row (col-span-2) with a top divider. At sm: the old flex row and full labels return.

Result

A shorter, even card

Closed card drops from 376px to 278px tall at 390px wide, both buttons are comfortable 44px tap targets, and the layout still fits at 320px with no overflow.

Keep this distinction

No button changes what it does. Regenerate, Export and the zoom switch call the exact same handlers as before — only their size, position and mobile label text change. Shorter labels are a mobile-only space trade, not a rename: desktop keeps “Regenerate Diagram” and “Export Diagram”.

2Export tools

Why this file changes

Inside the opened export panel, this button kept its big desktop padding on phones, so it did not match the panel's other button. It needs the same mobile sizing rule as its neighbour, Download PNG — one shared look for the panel's tools.

Input

Desktop padding on a phone

The button used p-4 padding with text-base at every screen size, making it bulky and a different height from the Download PNG button beside it in the panel.

This file

One class swap

The single changed line gives the button h-11 w-full (44px tall, full width) with text-sm on mobile. From sm: up it returns to the previous padding and size — sm:p-6 sm:text-lg, now with sm:h-10 sm:w-auto.

Result

A matched pair in the panel

Copy and Download PNG now line up at the same height and full width on mobile, so the opened panel reads as one tidy tool stack instead of two mismatched buttons.

Keep this distinction

This is one line of styling on one button — it does not change what gets copied. The Mermaid code, the click handler and the “copied” confirmation state all work exactly as before; only the button's mobile footprint changes.

export-dropdown.tsx

SUPPORTING — scan for surprises modified +5 −5

What this file does: it renders the panel that opens when you tap Export — the Download PNG button, plus the “Last generated” and “Actual cost” notes shown under it when they exist.

2Export tools

Why this file changes

When the panel opens on a phone it added a lot of height — loose spacing, a roomy button and full-size notes made the expanded card the tallest state of all, 516px. Tightening this panel is what brings that state down to 416px.

Input

An airy panel on mobile

space-y-4 gaps, a gap-3 button row with desktop padding, and text-sm notes — comfortable on desktop, wasteful on a 390px screen.

This file

Tighten, don't remove

Mobile spacing drops to space-y-3 and gap-2.5; Download PNG gets the same h-11 w-full treatment as the Copy button; both notes shrink to text-xs on mobile. Every value steps back up at sm:.

Result

Same panel, 100px shorter

Expanded card: 516px → 416px at 390px wide. Every control and both notes are still there — just closer together and right-sized on small screens.

Keep this distinction

Nothing is hidden on mobile to save space. Download PNG, “Last generated” and “Actual cost” all still render — they are smaller and tighter, not removed or deferred — and desktop spacing is completely unchanged.
